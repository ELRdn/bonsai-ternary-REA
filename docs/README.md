# Source documents

`README.md` is generated by concatenating these files in order:

1. `00_intro.md` — title, 3-line summary, TOC, 12 findings
2. `01_basics.md` — ternary quantization fundamentals
3. `02_overview.md` — Bonsai 2 family and architecture
4. `03_re.md` — methodology, GGUF anatomy, formats
5. `03b_conclusion.md` — the 42/128 zero mask and sign preservation
6. `04_rotation.md` — Hadamard fold/unfold
7. `05_kernels.md` — CPU/CUDA/Metal kernels and performance
8. `06_bench.md` — benchmarks and fact-check
9. `07_compare.md` — comparison with other ternary methods
10. `08_deploy.md` — deployment guide
11. `09_open.md` — open questions
12. `10_appendix.md` — math, reproduction, glossary, references

Regenerate the root README with:

```bash
python tools/assemble.py
```

The images in `assets/` are generated from `data/measurements.json` by
`tools/make_charts.py`.
